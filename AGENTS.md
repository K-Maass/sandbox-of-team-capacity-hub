## Capacity Hub AI architecture

- IBM AI credentials are server-side only.
- Never expose IBM credentials through `VITE_*` environment variables.
- Never commit credentials.
- LLMs interpret requests; deterministic TypeScript performs business logic.
- Never allow arbitrary SQL generated by the model.
- Future read and write actions must use typed interfaces.
- Ambiguous consultant or project names must trigger clarification.
- Future staffing writes require explicit user confirmation.
- Preserve Supabase user identity and existing Capacity Hub behavior.
- Do not introduce MCP or Orchestrate yet.
