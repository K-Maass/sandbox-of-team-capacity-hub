# Capacity Board

A visual consultant capacity and demand-management board.

## Features

- Manage consultants (name, surname, level, role).
- Track demand as projects, topics, or RfPs with status pipeline.
- Drag consultants onto demand cards to allocate capacity.
- Analytics dashboard with utilization, demand mix, and team composition charts.

## Tech stack

- [TanStack Start](https://tanstack.com/start) – React full-stack framework
- [TanStack Query](https://tanstack.com/query) – server-state management
- [Tailwind CSS v4](https://tailwindcss.com) – styling
- [shadcn/ui](https://ui.shadcn.com) – UI components
- [recharts](https://recharts.org) – charts

## Getting started

This project uses [Bun](https://bun.sh). Install dependencies with:

```bash
bun install
```

Start the development server:

```bash
bun dev
```

Then open [http://localhost:8080](http://localhost:8080).

## Available scripts

- `bun dev` – start the dev server
- `bun run build` – build for production
- `bun run build:dev` – build in development mode
- `bun run lint` – run ESLint
- `bun run format` – format with Prettier
